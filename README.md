# ☕ 5 to go Ploiești – Site (Sala Sporturilor)

Site demonstrativ (one-page) pentru cafeneaua **5 to go** din **Sala Sporturilor, Ploiești, Prahova** — cu meniu, program, locație pe hartă, recenzii și pagini legale (termeni și condiții, confidențialitate GDPR, cookie-uri).

## 📁 Structură

```
index.html                                # pagina principală
css/style.css                             # stiluri
js/main.js                                # meniu mobil, status deschis/închis, recenzii, banner cookie
pages/termeni-si-conditii.html            # termeni și condiții (șablon)
pages/politica-confidentialitate.html     # GDPR (șablon)
pages/politica-cookie.html                # politica cookie
```

## 🚀 Publicare pe GitHub Pages (gratuit)

1. `Settings` → `Pages`
2. Source: `Deploy from a branch`
3. Branch: `main`, folder: `/ (root)` → `Save`
4. Site-ul va fi disponibil la: `https://pablohype.github.io/5-to-go-ploiesti/`

## ⚠️ Important – marca „5 to go”

„5 to go” este o **marcă înregistrată**. Pentru a vinde cafea, a opera o cafenea sau a vinde site-ul ca „site 5 to go” ai nevoie de un **acord / franciză** de la proprietarul mărcii. Fără acest acord, site-ul poate fi folosit exclusiv ca **portofoliu / demonstrație**.
